ZK AIM PRO — Projeto Android

COMO GERAR O APK USANDO SOMENTE O CELULAR (GitHub Actions)

Você vai precisar de uma conta gratuita no GitHub e do navegador do celular.

1. Extraia este ZIP no celular usando o app Arquivos/Meus Arquivos.
2. No navegador, entre em https://github.com e crie uma conta ou faça login.
3. Crie um repositório novo chamado ZK-AIM-PRO. Deixe-o público ou privado e confirme em Create repository.
4. Dentro do repositório, toque em Add file > Upload files.
5. Envie TODO o conteúdo extraído desta pasta, incluindo a pasta oculta .github. Se o seletor do celular não mostrar arquivos ocultos, ative "mostrar arquivos ocultos" no gerenciador.
6. Confirme em Commit changes.
7. Abra a aba Actions do repositório.
8. Aguarde o processo "Build ZK AIM PRO APK" terminar com um visto verde. Se aparecer uma aprovação inicial, toque em "I understand my workflows, go ahead and enable them".
9. Abra a execução concluída e procure Artifacts.
10. Baixe ZK-AIM-PRO-APK.zip. Extraia e encontre app-debug.apk.
11. Toque no APK para instalar. Se o Android pedir, permita a instalação para o navegador/gerenciador de arquivos que você usou.

Se a opção de enviar pasta não aparecer no navegador móvel:
- No GitHub, abra o menu do navegador e marque "Versão para computador".
- Tente novamente em Add file > Upload files.
- Envie os arquivos e pastas preservando a estrutura (app/, .github/, build.gradle, settings.gradle e gradle.properties).

REQUISITOS:
- Projeto-fonte, não APK pronto.
- Android 6.0 ou superior no celular.
- A compilação acontece nos servidores do GitHub; não precisa instalar Android Studio no celular.

O QUE O APP FAZ:
Organiza ajustes anotados de sensibilidade e fornece recomendações gerais de estabilidade/FPS. Não altera o Free Fire, não injeta código e não oferece mira automática.
